## Changes

1. **FIR magnitude:** construct the complex desired spectrum using the proper
   `(taps-1)/2` delay before truncation/windowing. The previous integer-centered
   impulse plus symmetry averaging added a cos(pi*f/Fs) rolloff to every design.
   Flat48k/1024 response at16k changed from -6.0206dB to +0.0000735dB.
   Symmetry retained; coefficients/export carry the actual linear-phase delay.
   An even symmetric FIR still necessarily has a zero at exact Nyquist.
2. **Tick freshness:** visible polls explicitly pass their witnessed indices.
   Cached checked rows outside that frame become unknown; they cannot renew
   single-token or pair authorization. Per-row timestamps additionally expire
   active witnesses. Returning rows can re-arm only after3 valid observations.
   No new background scrolling is introduced. Keep all selected rows visible.
3. **Saved Fs:** both editions resolve through Known Documents; unknown or
   globally ambiguous edition cannot borrow Suite9 config. GUI calculations
   prefer the observer's exact source HWND, so Suite8+9 together can still bind
   to the correct config. Config path is part of the saved-Fs provenance token.
4. **AutoPhase worker:** immutable copies of TF arrays go to a dedicated single
   worker. Repeated clicks do not queue solves. Qt applies results only after
   rechecking source/ROI/selection generation, current native pair, file metadata
   and active tool. Close discards completions safely. Button shows busy state.
5. **TF matching:** interpolate log magnitude and unwrapped resolved phase,
   preserving a pure delay's amplitude instead of Cartesian chord attenuation.
   Reject near-half-turn or null-crossing interpolation segments; exact bins
   remain unchanged. Arbitrarily undersampled phase is not uniquely recoverable.
6. **FIR layout:** content height derives from actual layout/width, and the dock
   scroll area owns the viewport height. DSP selector/export and results no
   longer overlap. AutoPhase compact page/button sizing is unchanged.
